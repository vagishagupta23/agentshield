# AgentShield

Work in progress: build an AI agent, break it, then fix it and measure the difference.

- **Build:** an assistant that searches documents, summarizes a synthetic inbox, browses approved websites and calls tools over MCP.
- **Break:** an automated attack and evaluation suite that measures actual harmful outcomes, such as leaked synthetic secrets and unauthorized tool calls.
- **Fix:** a data-flow security layer that tracks where information comes from and what actions it is allowed to influence.

All emails, documents and secrets used here are synthetic.

## Status

Stage 1 (Build) is in progress. No benchmark results yet.
